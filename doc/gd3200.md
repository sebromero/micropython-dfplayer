# Control Commands

| Command (Hex) | Function                  | Parameters / Description                                                                                         |
|---------------|---------------------------|------------------------------------------------------------------------------------------------------------------|
| 0x01          | Next Song                 | N/A                                                                                                              |
| 0x02          | Previous Song             | N/A                                                                                                              |
| 0x03          | Play by Index             | Play specific track index (0-65535)                                                                              |
| 0x04          | Volume Up                 | Increases volume by one step (Max 30)                                                                            |
| 0x05          | Volume Down               | Decreases volume by one step (Min 0)                                                                             |
| 0x06          | Set Volume                | Parameter: Volume Level (0-30)                                                                                   |
| 0x07          | Set EQ                    | Parameter: 0=Normal, 1=Pop, 2=Rock, 3=Jazz, 4=Classic, 5=Bass                                                    |
| 0x08          | Single Song Loop          | Parameter: Track index (0-65535) to loop continuously                                                            |
| 0x09          | Specify Device            | Parameter: 1=USB, 2=TF/SD Card, 4=Flash                                                                          |
| 0x0A          | Sleep/Standby             | Enters low power mode (Wake up via ADK2 pin)                                                                     |
| 0x0C          | Reset                     | Soft reset the chip                                                                                              |
| 0x0D          | Play                      | Resume playback                                                                                                  |
| 0x0E          | Pause                     | Pause playback                                                                                                   |
| 0x0F          | Play File in Folder       | Para1: Folder (01-99); Para2: File (001-255). Note: Folder "FF" specifies root directory.                        |
| 0x11          | Loop All                  | 1: Start loop playback; 0: Stop loop playback                                                                    |
| 0x12          | Play from "MP3" Folder    | Play file from folder named "MP3". Supports indexes 0001-65535.                                                  |
| 0x13          | Interject Advertisement   | Play file from "ADVERT" folder. Resume background track when done.                                               |
| 0x14          | Play File in Large Folder | Supports folders 01-15 and files 0001-4095. Para1 (high 4 bits): Folder; Para1 (low 4 bits) + Para2: File index. |
| 0x15          | Stop Interjection         | Stop the current "ADVERT" insert and return to background music.                                                 |
| 0x16          | Stop                      | Stop playback completely.                                                                                        |
| 0x17          | Loop Folder               | Parameter: Folder name (01-99). Loops all files in that folder.                                                  |
| 0x18          | Random Play               | Randomly play all files on the device.                                                                           |
| 0x19          | Set Loop Mode             | 0: Enable single cycle loop; 1: Disable single cycle loop.                                                       |
| 0x1A          | Set Mute                  | 0: Unmute; 1: Mute.                                                                                              |
| 0x22          | Play Index & Volume       | (GD3300B Only) Set volume and play specific track index in one command.                                          |
| 0x25          | Interject Multi-Folder    | Play file from "ADVERT1" through "ADVERT9". Para1: Folder ID (1-9); Para2: File index (001-255).                 |


# System Status & Query Commands

| Command (Hex) | Function             | Parameters / Description                                                                           |
|---------------|----------------------|----------------------------------------------------------------------------------------------------|
| 0x3A          | Device Inserted Info | Response only. 01: U-Disk, 02: TF/SD, 04: PC connected.                                            |
| 0x3B          | Device Removed Info  | Response only. 01: U-Disk, 02: TF/SD, 04: PC disconnected.                                         |
| 0x3C          | U-Disk Track End     | Response only. Returns index of track just finished.                                               |
| 0x3D          | TF/SD Track End      | Response only. Returns index of track just finished.                                               |
| 0x3E          | Flash Track End      | Response only. Returns index of track just finished.                                               |
| 0x40          | Error/Busy           | Response only. System busy or error request.                                                       |
| 0x41          | ACK                  | Response only. Command received successfully.                                                      |
| 0x42          | Query Status         | Returns: 01=Playing, 02=Paused, 03=Stopped.                                                        |
| 0x43          | Query Volume         | Returns current volume level (00-30).                                                              |
| 0x44          | Query EQ             | Returns current EQ setting (0-5).                                                                  |
| 0x45          | Query Loop Mode      | Returns: 01=Loop All, 02=Single Loop, 03=Folder Loop, 04=Random, 05=Single Play, 06=Seamless Loop. |
| 0x46          | Query Version        | Returns software version.                                                                          |
| 0x47          | Query U-Disk Files   | Returns total file count on U-Disk.                                                                |
| 0x48          | Query TF Card Files  | Returns total file count on TF Card.                                                               |
| 0x49          | Query Flash Files    | Returns total file count on Flash.                                                                 |
| 0x4B          | Query U-Disk Track   | Returns current track index playing on U-Disk.                                                     |
| 0x4C          | Query TF Card Track  | Returns current track index playing on TF Card.                                                    |
| 0x4D          | Query Flash Track    | Returns current track index playing on Flash.                                                      |
| 0x4E          | Query Folder Files   | Returns total number of files in the current folder.                                               |
| 0x4F          | Query Folder Count   | Returns total number of folders on the current device.                                             |
